# stickie

Leave notes on code for your coding agent. It reads them, replies, and
resolves them: a review loop between you and the agent, kept beside the code.

stickie is a Node program. This package is its launcher for Python users:
`pip install stickie` (or `uvx stickie`) gives you the `stickie` and
`stickie-mcp` commands, which run the npm package of the same version through
`npx`. It needs Node.js 22 or later on your PATH.
